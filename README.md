## Featured Projects

### Fraud Detection Analysis

An end-to-end classification project using **594,643 synthetic financial transactions**. It compares Logistic Regression, Random Forest, and Gradient Boosting, tunes the probability threshold using validation data, and evaluates the selected model on an untouched test set.

**Result:** Gradient Boosting achieved **0.8065 F1**, **0.9973 ROC-AUC**, and **0.8943 PR-AUC**.

[![View Fraud Detection Analysis](https://img.shields.io/badge/View_Project-Fraud_Detection-14B8A6?style=for-the-badge&logo=github&logoColor=white)](https://github.com/YazeedAlzoubi05/Fraud-Detection-Analysis)

### E-Commerce Sales Analysis

An exploratory analysis of multichannel electronics sales across **Jordan and Lebanon**. The project combines sales and customer data, cleans inconsistent records, engineers business metrics, and investigates channel, product, customer, and time-based performance.

**Highlights:** 9,147 cleaned sales rows, 8,481 unique orders, product-pair analysis, and country-level year-over-year trends.

[![View E-Commerce Sales Analysis](https://img.shields.io/badge/View_Project-E--Commerce_Analysis-0E7490?style=for-the-badge&logo=github&logoColor=white)](https://github.com/YazeedAlzoubi05/Ecommerce-sales-analysis)

### Student Performance Prediction

A regression workflow using **Ridge Regression** to predict student performance. It includes exploratory analysis, categorical encoding, leakage-safe standardization, feature interpretation, and train/test evaluation.

**Result:** approximately **1.61 MAE** on a 0–100 performance scale.

[![View Student Performance Prediction](https://img.shields.io/badge/View_Project-Student_Performance-14B8A6?style=for-the-badge&logo=github&logoColor=white)](https://github.com/YazeedAlzoubi05/Predicting-Student-Performance)

### Expense Tracker

A Python command-line application supporting expense creation, viewing, updating, deletion, validation, local file persistence, overall spending totals, and category-level summaries.

[![View Expense Tracker](https://img.shields.io/badge/View_Project-Expense_Tracker-0E7490?style=for-the-badge&logo=github&logoColor=white)](https://github.com/YazeedAlzoubi05/Expense-Tracker-Project)
